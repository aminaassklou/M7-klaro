# Risques du projet Klaro

## 1. Risque de remboursement sans vérification

L'ancien bot peut annoncer un remboursement sans vérifier la commande.

Cela peut créer une erreur financière.

## 2. Risque lié au RGPD

Une décision avec un effet financier ne doit pas être prise automatiquement sans contrôle humain.

Dans la nouvelle architecture, le remboursement doit être validé par un humain.

## 3. Risque de biais d'automatisation

Avec l'Agent 3, un conseiller peut prendre l'habitude d'accepter les propositions de l'IA sans vérifier.

Il faut donc garder la possibilité de corriger la proposition.

## 4. Risque de surveillance des conseillers

Les données du pré-triage pourraient être utilisées pour surveiller le travail des conseillers.

Par exemple :
- combien de fois ils corrigent l'IA ;
- combien de temps ils mettent ;
- combien de propositions ils acceptent.

L'Agent 3 doit rester un outil d'aide, pas un outil de surveillance.
